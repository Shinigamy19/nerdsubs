# Test Audio Files

Place `.mp3`, `.wav`, or `.webm` audio files here for testing.

## Recommended test files

Download sample audio from Nerdearla's YouTube channel:
- Go to https://youtube.com/nerdearla
- Find a talk in English
- Download a 30-60 second clip
- Place it in this directory

## Supported formats
- MP3
- WAV
- WebM
- OGG
